# 지금 상태 — 무엇이 되고, 일부만 되고, 남았나

ddoc 3.0.0 기준(2026-11-25). "확인"은 테스트나 실제 실행으로 본 것이고, 확인하지 못한 것은 그렇게
적었습니다. 판정에 BLIND 가 있듯이, 이 페이지도 모르는 것은 모른다고 씁니다.

## 플러그인

| 플러그인 | 상태 | 확인 |
|---|---|---|
| categorical | 됨 | 테스트, 데모 |
| tabular | 됨 (EDA 보고서 렌더) | 테스트 |
| evidently | 됨 | 테스트 |
| timeseries | 됨 | 테스트 (torch 없는 전체 플러그인 환경에서 332개 통과) |
| audio | 됨 | 같은 환경에서 테스트 |
| vision | 됨 | torch + CLIP ViT-B/16 으로 e2e 테스트와 임베딩 지도 실제 실행. CLIP 은 플러그인에 들어 있어(MIT) GitHub 없이 설치됩니다 |
| text | 됨 | torch + CLIP 으로 e2e 테스트와 `diff --with-embeddings` 실제 실행(네트워크 없이). 내려받을 말뭉치 없음 — 단어는 정규식, 영어 불용어는 scikit-learn 목록 |

`ddoc doctor` 는 설치는 됐지만 불러지지 않는 플러그인을 빠진 모듈과 함께 보여줍니다.

## 알려진 한계

- **잡음 검정은 행이 서로 독립이라고 봅니다.** 판정은 열마다 JS 거리를 내고 표본 잡음으로 설명되는 차이는 0 으로
  두는데([판정 민감도](sensitivity.md)), 10분 간격 기상 기록처럼 이웃 행이 비슷한 시계열은 실제 정보량이 행 수보다
  훨씬 적습니다. 그만큼 작은 차이도 잡음을 넘는 것으로 보고, 판정은 변화의 크기(기준값)가 정합니다. 두 주씩
  떨어진 실제 날씨는 대체로 DRIFT 입니다([weather_station](../zoo/weather_station/)). 더 큰 변화부터 알리려면
  `--attr-threshold` 를 올리세요.
- **아주 작은 표본은 판정하지 않습니다.** 쪽마다 수십 행 이하에서는 완전히 갈라진 열도 우연과 구별되지 않아
  0점이고, 판정은 OK 에 표본 부족형·잠복 변화형이 붙습니다.
- **날짜·시간 열은 이름이나 값의 모양으로 찾습니다.** 연도 네 자리가 없는 형식(`7/1`, `2026년 7월 1일`,
  유닉스 시각 숫자 등)은 찾지 못해, 기간이 다른 두 데이터에서 늘 드리프트로 나올 수 있습니다.
  `ddoc probe` 로 미리 확인하세요.
- **누적값 열은 시간 열이 있을 때만, 값이 충분히 움직일 때만 알아봅니다.** 짧은 기간에 값이 두세 가지뿐인
  누적 열(나흘 동안의 주간 강우)은 알아보지 못해 비교에 남습니다.
- **임베딩 지도는 항목이 적으면 불안정합니다** (한쪽 20개 미만이면 표시). 같은 이미지만 있으면 중심
  이동을 계산하지 않습니다.
- **점수를 다시 매기지 못하는 플러그인 결과는 그 척도대로입니다.** vision·text·audio·timeseries 는 잰 값을,
  categorical 은 개수 분포를 넘겨 모두 같은 0–1 척도로 판정하지만, evidently 처럼 값을 넘기지 않는 플러그인의
  점수와 categorical 의 비율·통계 묶음은 플러그인이 낸 그대로입니다.
- **분포 비교만 합니다.** 라벨(정답)과의 관계가 바뀐 것(개념 드리프트)이나 모델 성능 영향은 라벨이 있는
  현재 데이터로 따로 재야 합니다.
- **주기성은 두 시점 비교로 구분하지 못합니다.** 요일·계절처럼 반복되는 차이는 비교 구간을 같은
  주기로 맞춰야 합니다([rhythm_not_drift](../zoo/rhythm_not_drift/) 참고).
