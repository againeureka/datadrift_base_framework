# 판정 민감도 — 점수 방식 비교

ddoc 3.0.0 기준(2026-11-24). 아직 정하지 않은 문제의 근거 자료이며, **기본값은 바뀌지 않았습니다.**
표는 `python zoo/sensitivity.py` 가 만듭니다(약 1분, 시드 고정). 이 스크립트는 ddoc 을 고치지 않고 내장 비교기
(`csv_diff`)의 결과 위에서 후보 규칙들을 계산합니다.

## 무엇이 문제인가

내장 CSV 비교기는 열마다 기준·현재 분포의 Jensen–Shannon 발산을 점수로 내고, 한 열이 0.25 이상이거나
평균이 0.15 이상이면 DRIFT 로 판정합니다. 이 규칙에 서로 반대 방향인 문제가 둘 있습니다.

1. **보통 크기의 데이터에서는 둔감합니다.** 변화 하나를 심은 드릴 가운데 9개가 OK 입니다. 평균이 1σ 움직여도
   점수는 0.19, 구성비가 30%p 바뀌어도 0.06 입니다. 한 열만 바뀐 경우 0.25 를 넘으려면 평균이 약 1.5σ
   움직여야 하고, 산포 변화·구성비 이동·새 범주는 시험한 범위(산포 3배, 40%p, 30%)에서 잡지 못합니다.
2. **작은 데이터에서는 오경보가 납니다.** 쪽마다 30행이면, 같은 분포에서 따로 뽑은 10열 표의 97% 가
   DRIFT 로 판정됩니다. 실제 `ddoc diff` 로 10번 비교해 10번 모두 `DRIFT high` 였고, 유형 판독도 같은
   잡음에 반응해 레짐 전환형·새 범주 등장 같은 유형을 "해당"으로 냈습니다.

원인은 하나입니다. 점수가 변화의 크기와 표본 잡음을 구분하지 않습니다. 20구간 히스토그램의 발산은 표본이
작으면 잡음만으로 커지고, 표본이 커도 실제 변화에 비해 작은 값이 나옵니다. 드릴이 1번만 보여준 이유는,
드릴의 "변하지 않은 열"이 같은 값을 순서만 섞은 것이라 점수가 정확히 0이기 때문입니다. 그래서 아래 2번 표는
따로 뽑은 표본으로 오경보를 잽니다.

## 비교한 방식

| 이름 | 열 점수 | 판정 기준 (평균 / 단일 속성) |
|---|---|---|
| 현행 JS 발산 | Jensen–Shannon 발산 (밑 2, 0–1) | 0.15 / 0.25 |
| JS 거리 | 발산의 제곱근 (0–1, 거리의 성질을 가짐) | 0.15 / 0.25 |
| PSI | 기준 10분위 구간의 population stability index (업계 관례 0.1 / 0.25) | 0.10 / 0.25 |
| JS 거리 + 잡음 거름 | JS 거리. 단, 같은 구간의 G-검정에서 차이가 표본 잡음으로 설명되면(p ≥ 0.001) 0 | 0.15 / 0.25 |
| + 판독 연동 | 위와 같음. 그리고 유형 판독이 "해당"인 열은 같은 잡음 검정을 통과하면 혼자서 DRIFT (결측 증가는 결측 개수로 검정) | 0.15 / 0.25 |

구간은 모두 지금 비교기와 같습니다(수치 열은 두 데이터를 합친 범위의 20구간, 적은 정수는 값마다, 범주는
값마다). PSI 만 기준 데이터의 10분위로 나눕니다.

## 읽는 법

- **JS 거리·PSI 만으로는 안 됩니다.** 보통 크기에서는 민감해지지만, 쪽마다 100행 이하에서는 거의 모든 표를
  DRIFT 로 판정합니다. 점수를 키우면 잡음도 같이 커집니다.
- **잡음 거름은 두 문제를 함께 풉니다.** 오경보가 30행에서도 1.5%, 300행부터 0 이면서 JS 거리의 민감도를
  그대로 가집니다. 표본이 커지면 잡음 거름은 거의 모든 차이를 통과시키므로, 그때 판정을 정하는 것은
  기준값(변화의 크기)이고, 그래서 1,000행과 5,000행의 결과가 같습니다.
- **판독 연동은 분포 점수가 원리상 못 보는 것을 잡습니다.** 결측 증가는 값의 분포를 바꾸지 않고, 소수의 극단값은
  넓은 구간 하나에 몰려 점수에 거의 드러나지 않습니다. 유형 판독은 둘 다 정확히 짚으므로, 판독이 잡음 검정을
  통과하면 판정에 반영하는 것이 자연스럽습니다. 드릴·이야기 19개를 모두 맞히고 오경보는 늘지 않습니다.
- **구성비 이동은 판독 연동 없이는 35%p 가 필요합니다.** 범주가 둘뿐이면 분포 거리가 작게 나오기 때문입니다.

## 제안 (결정 전)

1. 내장 CSV 비교기의 열 점수를 **JS 거리**로 바꾸고, 같은 구간의 G-검정에서 표본 잡음으로 설명되는 열은
   **0** 으로 둡니다 (유의수준 0.001, 열이 많아도 표 전체 오경보가 낮게 유지되는 수준).
2. **판독 연동**: 속성 유형이 "해당"이고 같은 잡음 검정을 통과한 열은 혼자서 판정을 DRIFT 로 만듭니다.
3. **기준값**은 0.15 / 0.25 를 유지하거나 단일 속성 기준을 0.2 로 내립니다(4번 표). 판독 연동이 있으면
   점수 기준은 "유형으로 설명되지 않는 분포 변화"만 맡으므로 0.25 로도 충분합니다.
4. **유형 판독에도 같은 잡음 검정**을 씌웁니다. 지금은 30행 표의 잡음에도 레짐 전환형 등이 "해당"으로
   나옵니다. 잡음 범위 안의 해당은 "가까움"으로 낮추거나 따로 표시합니다.
5. **드릴 보강**: 변하지 않은 열을 같은 분포의 독립 표본으로 바꾸고, 작은 표본의 무변화 드릴(OK 기대)을 더해
   오경보를 회귀 테스트로 고정합니다.

## 바꾸면 달라지는 것

- **점수 숫자가 커집니다** (발산 0.06 → 거리 0.25). 이전 보고서의 점수나 `--attr-threshold` 를 직접 지정한
  CI 설정과는 비교할 수 없으므로, 판정 규칙의 변경으로 버전과 변경 이력에 적어야 합니다.
- **잠복 변화형(hidden_change)의 뜻이 바뀝니다.** 지금은 "판정은 OK 인데 유형이 해당"이지만, 판독 연동 뒤에는
  "유형 조건은 채웠지만 표본 잡음 범위 안"이 됩니다. `hidden-change` 드릴은 다시 설계해야 합니다.
- **플러그인 점수는 별개입니다.** vision·audio·evidently 등은 MMD·Wasserstein·PSI 처럼 척도가 다른 점수를
  내므로 이 결정의 대상이 아닙니다. 범주 개수를 가진 categorical 플러그인은 같은 방식을 쓸 수 있습니다.
- 잡음 검정에 scipy 는 필요 없습니다 (χ² 꼬리 확률을 표준 라이브러리로 계산, scipy 와 1e-14 이내로 일치).

## 함께 발견한 것

- 기준 범위 밖 값이 5% 미만인 극단값(예: +30σ 에 2%)은 평균과 표준편차를 끌고 가서 "극단값 꼬리형"이 아니라
  "이동·확산형"으로 읽힙니다. 몸통(중앙값·사분위 폭)은 그대로이므로 꼬리형으로 읽는 편이 맞습니다.
