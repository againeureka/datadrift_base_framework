# 판정 민감도 — 점수 방식 비교

ddoc 3.0.0 기준(2026-11-26). 판정 규칙을 고른 근거 자료입니다. 표의 **+ 판독 연동 (현행)** 이 지금 `ddoc diff`
가 쓰는 규칙이고([ddoc.scoring](../ddoc/scoring.py)), **이전: JS 발산** 이 그 전의 규칙입니다. 5번 표는 시간
순서 기록의 잡음 검정(행 단위 → 하루 단위)을 비교합니다. 표는 `python zoo/sensitivity.py` 가 만듭니다(약 2분,
시드 고정).

## 무엇이 문제였나

이전의 내장 CSV 비교기는 열마다 기준·현재 분포의 Jensen–Shannon 발산을 점수로 내고, 한 열이 0.25 이상이거나
평균이 0.15 이상이면 DRIFT 로 판정했습니다. 이 규칙에는 서로 반대 방향인 문제가 둘 있었습니다.

1. **보통 크기의 데이터에서는 둔감했습니다.** 변화 하나를 심은 드릴 가운데 8개가 OK 였습니다. 평균이 1σ
   움직여도 점수는 0.19, 구성비가 30%p 바뀌어도 0.04 였고, 산포 변화·구성비 이동·새 범주는 시험한 범위에서
   잡지 못했습니다.
2. **작은 데이터에서는 오경보가 났습니다.** 쪽마다 30행이면 같은 분포에서 따로 뽑은 10열 표의 97% 가 DRIFT
   였고, 유형 판독도 같은 잡음에 반응했습니다.

원인은 하나입니다. 점수가 변화의 크기와 표본 잡음을 구분하지 않았습니다. 20구간 히스토그램의 발산은 표본이
작으면 잡음만으로 커지고, 표본이 커도 실제 변화에 비해 작은 값이 나옵니다. 플러그인은 또 저마다 척도가
달랐습니다(vision 은 PSI, text 는 평균으로 나눈 Wasserstein, audio 는 Hz 단위 Wasserstein, timeseries 는 원래
단위의 차이). 같은 기준값 0.15 / 0.25 가 모두에 적용되었는데도 말입니다.

## 비교한 방식

| 이름 | 열 점수 | 판정 기준 (평균 / 단일 속성) |
|---|---|---|
| 이전: JS 발산 | Jensen–Shannon 발산 (밑 2, 0–1) | 0.15 / 0.25 |
| JS 거리 | 발산의 제곱근 (0–1, 거리의 성질을 가짐) | 0.15 / 0.25 |
| PSI | 기준 10분위 구간의 population stability index (업계 관례 0.1 / 0.25) | 0.10 / 0.25 |
| JS 거리 + 잡음 거름 | JS 거리. 단, 같은 구간의 G-검정에서 차이가 표본 잡음으로 설명되면(p ≥ 0.001) 0 | 0.15 / 0.25 |
| + 판독 연동 (현행) | 위와 같음. 그리고 유형 판독이 "해당"인 열은 같은 잡음 검정을 통과하면 혼자서 DRIFT (결측 증가는 결측 개수로 검정) | 0.15 / 0.25 |

구간은 모두 비교기와 같습니다(수치 열은 두 데이터를 합친 범위의 20구간, 적은 정수는 값마다, 범주는 값마다).
PSI 만 기준 데이터의 10분위로 나눕니다. 드릴의 "변하지 않은 열"은 같은 분포에서 따로 뽑은 표본이라 실제 표본
잡음을 가집니다.

## 읽는 법

- **JS 거리·PSI 만으로는 안 됩니다.** 보통 크기에서는 민감해지지만, 쪽마다 100행 이하에서는 거의 모든 표를
  DRIFT 로 판정합니다. 점수를 키우면 잡음도 같이 커집니다.
- **잡음 거름은 두 문제를 함께 풉니다.** 오경보가 30행에서도 1.5%, 300행부터 0 이면서 JS 거리의 민감도를
  그대로 가집니다. 표본이 커지면 잡음 거름은 거의 모든 차이를 통과시키므로, 그때 판정을 정하는 것은
  기준값(변화의 크기)이고, 그래서 1,000행과 5,000행의 결과가 같습니다.
- **판독 연동은 분포 점수가 원리상 못 보는 것을 잡습니다.** 결측 증가는 값의 분포를 바꾸지 않고, 소수의 극단값은
  넓은 구간 하나에 몰려 점수에 거의 드러나지 않습니다. 유형 판독은 둘 다 정확히 짚으므로, 판독이 잡음 검정을
  통과하면 판정에 반영합니다. 드릴·이야기를 모두 맞히고 오경보는 늘지 않습니다.
- **구성비 이동은 판독 연동 없이는 35%p 가 필요합니다.** 범주가 둘뿐이면 분포 거리가 작게 나오기 때문입니다.
- **시간 순서 기록은 하루 단위로 세야 합니다.** 10분 간격 기록은 이웃 값끼리 닮아서, 행을 하나씩 세면 변화가
  없어도 71–95% 를 DRIFT 로 판정합니다(5번 표). 하루 단위로 세면 하루끼리 독립에 가까울 때 오경보가 0 이고,
  날씨처럼 하루가 전날을 닮을수록(ρ 0.5–0.7) 9–14% 로 늘어납니다. 행 단위보다는 훨씬 낫지만 남은 한계입니다.
  두 기간이 날마다의 수준 차이의 두 배쯤 갈라지면 85–95% 를 잡습니다. 실측 기록에서는 장마와 계절은 그대로
  DRIFT 이고, 날씨가 그대로였던 연간 초기화와 나흘 대 나흘은 OK 가 됩니다.

## 채택한 것

1. 열 점수는 **JS 거리**이고, 같은 구간의 G-검정에서 표본 잡음으로 설명되는 열은 **0** 입니다(유의수준 0.001, 열이
   많아도 표 전체 오경보가 낮게 유지되는 수준). 결과 JSON 의 요약에 검정의 p 가 `noise_p`(값 분포)와
   `missing_p`(결측 개수)로 남습니다.
2. **판독 연동**: 속성 유형이 "해당"이고 같은 잡음 검정을 통과한 열은 혼자서 판정을 DRIFT 로 만들고, 판정 근거에
   "속성 'x'에서 ○○형이 표본 잡음 범위를 넘어 확인됩니다"가 나옵니다.
3. **기준값**은 0.15 / 0.25 그대로입니다. 판독 연동이 있으면 점수 기준은 "유형으로 설명되지 않는 분포 변화"만
   맡으므로 0.25 로 충분합니다(4번 표). 더 일찍 알리려면 `--attr-threshold 0.2`.
4. **유형 판독에도 같은 잡음 검정**: 잡음 범위 안의 "해당"은 "가까움"으로 낮추고, 판정이 OK 이면 **잠복
   변화형**("유형 조건은 채웠지만 표본 잡음 범위 안")으로 알립니다.
5. **드릴 보강**: 변하지 않은 열을 같은 분포의 독립 표본으로 바꾸고, 작은 표본의 무변화 드릴(`small-unchanged`,
   OK 기대)과 잡음 범위 안의 변화 드릴(`hidden-change`, OK 기대)을 더했습니다.
6. **모든 데이터에 같은 척도.** 항목마다 잰 값을 넘기는 플러그인(vision·text·audio·timeseries)의 속성과
   categorical 플러그인의 개수 분포도 같은 방식으로 매기고, 임베딩 지도는 `embedding_separation`(1 − 이웃
   섞임, 이웃 구성의 같은 잡음 검정)으로 한 속성이 됩니다. 플러그인이 낸 원래 점수는 결과 JSON 의
   `plugin_scores` 에 남습니다.
7. **시간 순서 기록은 묶어서 검정합니다.** 시간 열이 있으면(timeseries 플러그인은 `timestamp_column`) 행을
   달력 날짜로 묶고, 한쪽이 3일 미만이면 그쪽을 같은 길이의 6구간으로 자릅니다. 잡음 검정은 두 기간의 차이가
   블록끼리의 차이보다 큰지를 봅니다(G 통계량의 2차 Rao–Scott 보정, 블록 자유도의 F 검정, 행 단위 검정보다
   관대해지지 않음). 결과 JSON 의 `profile.noise_blocks` 에 묶은 방식이, 요약의 `design_effect` 에 설계효과
   (대략 몇 행이 한 행 몫인지)가 남습니다. 한 시간 같은 짧은 블록은 이웃 블록끼리 닮아 같은 문제가 남으므로
   쓰지 않습니다.

## 바뀐 것

- **점수 숫자가 커졌습니다** (발산 0.06 → 거리 0.25). 이전 보고서의 점수나 `--attr-threshold` 를 직접 지정한 CI
  설정과는 비교할 수 없습니다.
- **잠복 변화형(hidden_change)의 뜻이 바뀌었습니다.** 전에는 "판정은 OK 인데 유형이 해당"이었고, 이제는 "유형
  조건은 채웠지만 표본 잡음 범위 안"입니다.
- **아주 작은 표본은 OK 가 됩니다.** 쪽마다 3행이 완전히 갈라져도 우연히 그렇게 나뉠 확률이 1/20 이라 잡음
  검정을 통과하지 못합니다. 판정은 OK 이고 표본 부족형·잠복 변화형이 그 사정을 알립니다.
- **실측 시계열은 날마다의 차이를 넘어야 DRIFT 입니다.** 날씨가 그대로였던 연간 초기화와 나흘 대 나흘은 OK 가
  되고, 장마에서도 점수가 남는 열이 줄었습니다(0.333 → 0.244, 11개 열 중 6개). 시간 열이 없는 표는 그대로입니다.
- 잡음 검정에 scipy 는 필요 없습니다 (χ² 와 F 꼬리 확률을 표준 라이브러리로 계산, scipy 와 각각 1e-14, 1e-9 이내로 일치).
